# AC8 VR システム総合検証手順書 (v20)

本ドキュメントは、**「360° JHMCS 追従」**、**「僚機常時表示」**、**「ターゲットマーカー拡縮（Discord映像機能）」**、および **「HUD・パフォーマンス安定性」** が正常に機能しているかを確認するための検証チェックリストです。

---

## 🔍 各項目の詳細テスト手順

### TEST 1: 小隊僚機（Professor / Tasha）の 360° 永続追従
1. ミッション（またはフリーフライト/訓練）を開始します。
2. 出撃直後、機首を真っ直ぐ向けたまま **首だけを右、左、後方へ振ります**。
3. **合格基準**:
   - 僚機の護衛アイコン `[W]` およびコールサイン（`PROFESSOR` 等）が、コックピットの窓枠を越えて 360° 全周囲に表示されていること。
   - 旋回やループ（宙返り）をしても、僚機マーカーがチカチカ点滅したり消滅したりしないこと。

---

### TEST 2: ターゲットマーカー拡縮（サイズ変更テスト）
1. **Insertキー** で UEVR メニューを開きます。
2. 左メニュー最下部の **`LuaLoader` → `Script UI`** をクリックします。
3. **`AC8 JHMCS & Target Scaler`** セクションを見ます。
4. **`Marker Scale`** のスライダー（または **`[Large (2.0x)]`** / **`[Small (0.7x)]`** ボタン）をクリックします。
5. **合格基準**:
   - 視界内および視界外にあるターゲット枠（四角枠）、僚機マーク（`[W]`）、コールサイン文字の大きさが、スライダーの動きに合わせて **リアルタイムに変化** すること。
   - 枠が消えてしまったり（Case 1 のバグ）、サイズが変わらなかったり（Case 2 のバグ）しないこと。

---

### TEST 3: 敵機の 360° 追従 ＆ 撃破ハンドシェイク
1. 正面に敵機を捉え、ターゲット枠が表示された状態にします。
2. 首を大きく横に振り、**敵機を機首の正面コックピットHUD（約50°以内）から外します**。
3. そのまま首を回して敵機を目視します。
4. ミサイル等で敵機を撃墜します。
5. **合格基準**:
   - 機首が向いていなくても、敵機の周囲に枠が 360° 追従して表示されていること。
   - 敵機を撃墜した瞬間、枠がその場に残骸として残らず、**通常プレイと同じようにパッと消去** されること。

---

### TEST 4: 地上・山岳目標の維持テスト
1. 地上目標（山の上にあるSAMやレーダー施設など）が存在するエリアを飛びます。
2. 地上目標から視線を外して旋回し、再度その方向を見ます。
3. **合格基準**:
   - 生きている地上目標が、1秒以上経過しても理不尽に消えずに表示され続けていること。

---

### TEST 5: パフォーマンスとエラーログ確認
1. 高速旋回や急上昇・急降下を行い、機体操作をします。
2. **合格基準**:
   - 前回のテストであったような **「クッソ重くてプレイにならない」というスタッター（引っかかり）が完全に消え、滑らかに動くこと**。
   - UEVR メニュー（`LuaLoader` → `Main` または上部ログ）に赤文字のエラー（`sol: runtime error: Property 'bHiddenInGame' not found` など）が記録されていないこと。

---

### TEST 6: HUD 健全性とスコア位置・GLOW
1. 正面コックピットの計器（ピッチラダー、速度・高度、レーダー）が消えずに正しく表示されているか確認します。
2. `Script UI` の **`AC8 HUD`** にて、画面左上の **`Score / MissionInfo`** の位置スライダーを動かして位置が移動するか確認します。
3. 各パーツの **`GLOW`** チェックボックスの ON/OFF が個別に切り替えられるか確認します。

---
