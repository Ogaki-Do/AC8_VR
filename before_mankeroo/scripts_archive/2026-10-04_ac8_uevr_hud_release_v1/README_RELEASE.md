# 『ACE COMBAT 8』 UEVR 完全動作版 HUD 修正スクリプト パッケージ (v1.0 完成版)

- **作成日時**: 2026年10月4日
- **対象ゲーム**: 『ACE COMBAT 8』
- **動作プラットフォーム**: UEVR (Unreal Engine VR Mod) / PC VR

---

## 概要

本パッケージは、Flat2VRコミュニティの先行研究スクリプトをベースに、実機テストで発生していた致命的な不具合（格納庫カメラ位置の歪み、出撃時の10秒遅延、ミッション離脱時のデッドロック・フリーズ、手動「Reload targets」の必要性）をすべて修正・改良した**完成版スクリプト群**です。

---

## 主な特徴・修正点

1. **公式ネイティブHUD・ピッチラダーの完全表示と位置補正**
   - ゲーム本来のピッチラダー（Pitch Ladder）、対気速度計（Airspeed）、気圧高度計（Altimeter）、速度ベクトル（Velocity Vector / W標）がコックピット視界と完全に同期します。
   - `data/ac8_ladder.json` による位置微調整の永続保存に対応。

2. **シーン遷移・出撃の100%全自動化（手動ボタン操作不要）**
   - コミュニティ版ではミッション開始時にUEVRメニューを開いて「Reload targets」を手動で押す必要がありましたが、プレイヤーPawnの生成・切り替えを自動検知して0.016秒（1フレーム）で即座にHUDを捕捉・位置補正します。

3. **出撃時の「10秒遅延」の完全撤廃**
   - メニュー・格納庫中の探索退避タイマー（指数バックオフ）が出撃時にも残存していた問題を修正。Pawnの変化と同時にタイマーを即時リセットし、出撃した瞬間にHUDが表示されます。

4. **ミッション離脱・メニュー遷移時のフリーズ／デッドロック根絶**
   - 以前はミッション終了時（フリーミッション離脱時等）に、メモリから破棄されつつあるHUDウィジェットをLuaが探し回ったり、Slate描画スレッドからアクセスしてしまい、ゲームエンジンが完全硬直（デッドロック）していました。
   - 厳格なフライト状態ガード（`is_flight_active()`）を実装し、非フライト時（メニュー・格納庫・ロード中）は一切のUI操作・メモリ探索を安全に休眠させることで、クラッシュやフリーズを根絶しました。

5. **格納庫・メニューのカメラ位置正常化**
   - VRカメラ剛性アンカー処理およびカメラアニメーション停止フックをフライト中のみに限定。格納庫での機体鑑賞カメラや旋回アニメーションがゲーム本来の正常な挙動を維持します。

## ファイル構成

```text
├── scripts/
│   ├── ac8_hud_inspect_v129.lua     # 中央HUD・速度計・高度計・速度ベクトルの位置合わせ＆カメラ剛性アンカー
│   ├── ac8_ladder_fix_v19_fast.lua  # ピッチラダーの最適化移動＆自動シーン遷移検知・描画保護
│   └── ac8_cutscene_guard_v1.lua    # カットシーン時の2D自動フォールバック保護ガード
├── data/
│   └── ac8_ladder.json              # ピッチラダー等の位置・スケール設定値ファイル
├── config.txt                       # UEVR本体のプロファイル設定
└── README_RELEASE.md                # 本マニュアル
```

## 復元・再導入手順

環境の移行や再インストールの際は、以下の手順で配置してください：

1. `scripts/` フォルダ内の3つの `.lua` ファイルを以下にコピー：
   `%APPDATA%\UnrealVRMod\AceCombat8\scripts\`
2. `data/` フォルダ内の `ac8_ladder.json` を以下にコピー：
   `%APPDATA%\UnrealVRMod\AceCombat8\data\`
3. 必要に応じて `config.txt` を以下にコピー：
   `%APPDATA%\UnrealVRMod\AceCombat8\`
