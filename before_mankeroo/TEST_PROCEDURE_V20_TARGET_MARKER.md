# ACE COMBAT 8 : ターゲットアイコンサイズ変更 検証手順書 (v20)
**作成日時**: 2026-10-07  
**検証スクリプト**: `ac8_target_3d_test.lua` (v20 Ultra-Lean)  
**本採用稼働中**: `ac8_m_jhmcs.lua` (360°全周JHMCSロック機能)  

---

## 0. 開発方針の再確認（固い決意）
> **「自力で書く機能（自前UIの生成）はきっぱり断念！ターゲットアイコンサイズを変更するのは絶対にあきらめない！」**

- 過去の教訓通り、描画スレッドでの自前UI生成や文字枠代替（`[ ]`）はクラッシュ（Error 0）を招くため永久封印しました。
- 今回は、**ゲーム本来の四角枠（`ContainerBox`）本体のシェーダー・マテリアル・ビルボード描画パラメータ**に正攻法で直接介入し、ターゲットアイコンのサイズ変更を徹底追及します！
- **「空中の全ターゲット機に一括反映」** されるため、どの敵機を見ていても即座に効果を確認できます。

---

## 1. 今回（v20）の変更点と改善

1. **完全クラッシュフリー設計（ゲームスレッド専用）**:
   - 出撃時や飛行開始時のクラッシュ（Error 0）要因であった描画スレッド（Slate Draw）フックを完全撤廃。
   - `on_post_engine_tick`（ゲームスレッド）のみで安全に動作します。
2. **極限まで削ぎ落とした「1ケース = 1スライダー + 1リセット」**:
   - 組み合わせテストは一切不要。
   - 不要な機能・UI・ボタン・ダンプ用メニューはすべて削除し、5つのスライダーのみを配置。
3. **マテリアル直接取得の修正**:
   - 以前のテスト（v16）では、ビルボードの仕様によりマテリアル取得がスキップされていました。
   - 今回は四角枠の描画要素（Element 0）から実在する動的マテリアル（`MID_M_HUD_TargetContainer3DUI_000`）を直接取得してパラメータを書き換えます。

---

## 2. テスト手順（1スライダーずつ動かす）

1. UEVRメニューを開き、**`Reset Scripts`** を押してください。
2. UEVRメニュー内に **`AC8 Target Icon Scaler (v20)`** が表示されます。
3. **上から順に、スライダーを1つずつ大きく動かして四角枠の変化を確認してください。**
4. 確認後は、横の **`[Reset]`** ボタンを押して初期値に戻してから次のケースに進んでください。

| ケース番号 | スライダー操作 | 検証内容・狙い | リセット操作 |
| :--- | :--- | :--- | :--- |
| **Case 1** | `Shader Reticle Scale (1.0~5.0)` | マテリアルの拡大倍率変数（`Scale` / `ReticleScale` / `BoxScale` 等）を一括書き換え（**3.0〜5.0** に動かす） | `[1.0 Reset]` |
| **Case 2** | `Shader Reticle Size (32~512)` | マテリアルのサイズ変数（`Size` / `ReticleSize` / `BoxSize` 等）を書き換え（**300〜512** に動かす） | `[128 Reset]` |
| **Case 3** | `Shader UV Scale (0.2~5.0)` | テクスチャのUV拡大率（`UVScale` / `Tiling` / `Zoom` 等）を書き換え（**2.0〜5.0** に動かす） | `[1.0 Reset]` |
| **Case 4** | `Diagnostic Color Shift (0.0~1.0)` | **【マテリアル疎通診断】** 緑色の四角枠が **赤紫色（マゼンタ）に変色するかテスト**（**1.0** に動かす）<br>※変色すれば、マテリアル変数による四角枠の直接操作が成功している決定的証拠になります！ | `[0.0 Reset]` |
| **Case 5** | `Billboard AddElement BaseSize (64~1024)` | ビルボードに実在マテリアルと拡大サイズ（**512〜1024**）を指定して描画要素を直接再構築 | `[128 Reset]` |

> ※ 画面最下部の **`[=== Reset All 5 Sliders to Default ===]`** を押すと、全スライダーが一括で初期値に戻ります。
