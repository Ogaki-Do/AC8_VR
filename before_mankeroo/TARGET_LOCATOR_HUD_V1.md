## 1. コンセプトと実現メカニズム

### ① ピッチラダーと同じ空間（HUD中央・レティクル基準）に配置
ピッチラダー（人工水平儀）の研究で確立された大原則：
> **「自前描画を行わず、MainFlightキャンバス内の公式アセットを活用してコックピット正面のHUD中央に配置する」**

本作でも、ピッチラダーやフライトパスマーカー（中央緑丸レティクル）と**全く同一の基準中心座標（`MainCanvas` 中央空間）** をベースとしています。

### ② 3次元ベクトル解析 $\to$ 2D HUD円周上への極座標投影
1. **リアルタイム相対角の算出**:
   - 自機（Pawn）のワールド位置・回転（Pitch, Yaw, Roll）と、ロックオン敵機のワールド位置から、自機機首基準の相対方位角（水平アジマス角・垂直エレベーション角）を毎フレーム計算。
2. **視界外（Off-screen）判定**:
   - 敵機がコックピット正面視野角（デフォルト $\pm 22^\circ$）から外れた場合、または機首後方に回った瞬間に**矢印表示トリガーが自動起動**。
   - 敵機が正面視野内に戻ると、照準枠と重複しないよう**矢印は自動的に非表示（消灯）**。
3. **HUD円周上への投影**:
   - ピッチラダーの水平線・レティクル中心から、指定半径（Radius: デフォルト 320 px）の円周上へ敵機方向の角度で矢印を配置。
   - 矢印自身の向き（`RenderTransformAngle`）も敵機の方向へリアルタイム回転追従。

### ③ トリプルモード（公式パーツ連携）
- **Mode 0: ネイティブ `WBP_LocatorWidget` 直接制御**
  - ゲーム本来の視界外ロケーターウィジェットを目覚めさせ、位置・角度・スケールを直接制御。
- **Mode 1: ピッチラダー公式パーツ `LandingGuideBar` 連携**
  - ピッチラダーの復活で大成功を収めた公式針パーツ（`LandingGuideVertical`）を流用し、HUD中央から敵機方向へ誘導針・三角バーを表示。
- **Mode 2: デュアル・ハイブリッド（両方同時表示）**
  - ネイティブロケーターとガイドバーを両方同時に連動表示。

## 2. インゲームでの使用方法・カスタマイズ

1. 出撃（または訓練飛行）を開始します。
2. キーボードの **`Insert`** キーを押し、UEVRメニューを開きます。
3. **`Script UI`** に追加された **`AC8-Target-Locator-HUD`** を開きます。

### 主な調整項目（リアルタイム反映・自動保存）

| 項目名 | デフォルト値 | 説明 |
| :--- | :---: | :--- |
| **Enable Target Locator Arrow** | ON | システム全体の有効 / 無効切り替え |
| **Render Mode** | Mode 0 | 0: LocatorWidget / 1: LandingGuideBar / 2: Dual Hybrid |
| **Ring Radius (px)** | 320.0 px | HUD中央レティクルからの距離（円周の半径） |
| **Arrow Length (Scale X)** | 1.8 | 矢印の長さ（拡大率） |
| **Arrow Width (Scale Y)** | 1.8 | 矢印の太さ（拡大率） |
| **Opacity** | 1.0 | 矢印の不透明度（0.1 〜 1.0） |
| **Center Offset X / Y** | 0.0 px | HUD中央に対する中心位置の微調整 |
| **FOV Threshold** | 22.0° | 矢印が出現する視界外角度のしきい値 |
| **Invert Arrow Angle** | OFF | 矢印の回転方向（時計回り/反時計回り）の反転 |
| **Angle Fine-Tune** | 0.0° | 矢印の向きの微調整（-180° 〜 +180°） |
| **カラーボタン** | Green | クラシック緑 / アラート赤 / シアン青 をワンクリック変更 |

※ 設定した数値は `data/ac8_locator_config.txt` に自動保存され、次回起動時も維持されます。
