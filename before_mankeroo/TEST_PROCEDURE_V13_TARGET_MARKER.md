# ACE COMBAT 8 : ターゲットマーカー検証手順書 (v13)
**作成日時**: 2026-10-07  
**検証スクリプト**: `ac8_target_3d_test.lua` (v13)  
**目的**:
- **【テストA】**: 正面（100度FOV内）でテキストサイズ拡大を維持できる「適切な描画フェーズ（タイミング）」の特定
- **【テストB】**: 四角枠アイコン（`ContainerBox`）のサイズ変更手法（`AddElement` / 3Dスケール / MIDマテリアル）の特定

---

## 0. 事前準備
1. ゲーム内で敵機が飛行している状態（ミッション中、またはフリーフライト等の訓練空域）にします。
2. UEVRメニュー（OpenXRメニュー）を開き、**Scripting** タブから **`AC8 Target Marker Scaler (v13) : Test A & Test B`** のウィンドウを表示します。
3. 画面上部のタブ切り替えボタンで **`[TEST A]`** または **`[TEST B]`** を選択します。

---

## 1. 【テストA】テキストサイズ変更：適切なタイミング（描画フェーズ）の調査

### 目的
正面（HUDの100度以内）を向いたとき、ゲーム側のHUDリセット処理を「どの描画フェーズの後出し適用」で打ち負かせるかを完全特定します。

### 手順
1. **タブを `[TEST A]` に切り替えます**。
2. **`Test Text Scale`** スライダーを **`3.0x`** または **`5.0x`** に設定します（文字がはっきり巨大化するサイズ）。
3. 以下の各フェーズを「単体」または「組み合わせ」でチェックし、**敵機を正面に捉えた状態で文字が巨大化したまま維持されるか**を確認します：

| パターン | チェック設定 | 検証の着眼点 |
| :--- | :--- | :--- |
| **A-1: 通常エンジンTickのみ** | `[x] Phase 1` のみON<br>(プリセットボタン `Only Phase 1` を押す) | 正面を向くと文字が標準サイズに戻る（リセットされる）か確認。 |
| **A-2: VRステレオ計算直後** | `[x] Phase 3` のみON<br>(プリセットボタン `Only Phase 3` を押す) | **本命候補①**：VR両目カメラ計算直後。正面でも文字がデカいまま維持されるか？ |
| **A-3: レンダースレッド描画直前** | `[x] Phase 4` のみON<br>(プリセットボタン `Only Phase 4` を押す) | **本命候補②**：画面描画直前のレンダースレッド。正面でも文字がデカいまま維持されるか？ |
| **A-4: 全フェーズ同時適用** | `[x] ALL Phases ON` を押す | 全フェーズで連続適用した場合、正面・視界外問わず完全に巨大化が維持されるか？ |

### 判定基準
- 正面を向いても距離の数字や機体名が**巨大なまま安定していれば、そのフェーズが「ゲーム側リセットを打ち負かした適切なタイミング」**と確定します。
- 各チェックボックス横の `[XX fps]` 表示で、そのフックが毎秒何回稼働しているかがリアルタイム確認できます。

## 2. 【テストB】四角枠アイコン（ContainerBox）のスケール変更テスト

### 目的
依然としてサイズが変わっていない「四角いターゲット枠本体」に対し、UEの各描画層からサイズ変更を試みます。

### 手順
1. **タブを `[TEST B]` に切り替えます**。
2. **`Target Airplane`** スライダーでテスト対象を選びます（`1` = ターゲット1番のみ、`0` = 全機一括）。
3. 以下の3つの手法を順番に試します：

#### 手法 B1: `AddElement` による直接サイズ注入（本命）
1. **`BaseSize`** スライダーを **`512.0`** または **`1024.0`**（特大）に設定します。
2. **`bSizeIsInScreenSpace`**（ピクセル単位）にチェックが入っていることを確認します。
3. **`>> INJECT AddElement ON CONTAINER BOX <<`** ボタンをクリックします。
4. **確認**: 四角枠が巨大化するか、または新しい枠が出現するか？
   *(※ Candidate Material の `Next Mat >` で別のマテリアルに切り替えて再クリックも可能です)*

#### 手法 B2: コンポーネント3Dスケール & バウンド拡張
1. **`ContainerBox RelativeScale3D`** を `3.0x` に動かす。
2. **`ContainerBox WorldScale3D`** を `3.0x` に動かす。
3. **`BoundsScale`** を `5.0x` に動かす（カリング防止）。
4. **確認**: 四角枠の大きさに変化が出るか？

#### 手法 B3: マテリアル（MID）パラメータ直接操作
1. **`MID 'Scale'`** を `5.0` に設定。
2. **`MID 'Size'`** を `500.0` に設定。
3. **`>> Apply MID Parameters on ContainerBox <<`** ボタンをクリック。
4. **確認**: シェーダー側のスケーリングで枠サイズが変わるか？
